# تقرير وثائقي شامل لميزات منصة «المُميز»

> وثيقة وظيفية تصف المنصة **كما هي الآن في الكود**، مخصصة لتسليمها لمصمم UI/UX أو لعميل لفهم كل الإمكانيات الحالية. لا تحتوي على أي اقتراحات أو تطويرات.

---

## القسم الأول: معلومات عامة

- **اسم المنصة:** المُميز — منصة محمد عفيفي التعليمية.
- **نوع المنصة:** منصة تعليمية إلكترونية (E-Learning) لتدريس مادة اللغة العربية عن بُعد، تعمل عبر المتصفح ويدعمها تطبيق جوال (عبر إشعارات FCM).
- **الفئة المستهدفة:** طلاب التعليم قبل الجامعي في مصر (ابتدائي، إعدادي، ثانوي)، وأولياء أمورهم، والمعلم/الإدارة.
- **نوع المستخدمين:**
  - **طالب:** المستخدم الأساسي الذي يتصفح الكورسات ويشاهد الدروس ويحل الاختبارات.
  - **مدرس / مسؤول (Admin):** يدير المحتوى والطلاب والاشتراكات والإشعارات والتحليلات.
  - **ولي أمر (Parent):** يرى تقدم أبنائه عبر دعوة مرتبطة بحساب الطالب.
  - **زائر تجريبي (Guest / Demo):** وضع تجريبي يفتح محتوى محدداً للعرض دون تسجيل دخول.

---

## القسم الثاني: حساب الطالب

- **تسجيل الدخول:** يدخل الطالب ببريده الإلكتروني وكلمة المرور، أو عبر حساب Firebase، أو عبر بوابة مخصصة لولي الأمر. كلمة المرور محفوظة بشكل آمن ومُقارنة بشكل آمن.
- **إنشاء حساب:** يُسجَّل الطالب بـ (الاسم، البريد، الهاتف، هاتف ولي الأمر، الصف، المرحلة، المحافظة، كلمة المرور، كود دعوة اختياري). يُنشأ تلقائياً كود دعوة خاص به.
- **تأكيد البريد الإلكتروني:** يُرسل كود عبر البريد، ويُفعَّل الحساب عند إدخاله.
- **استعادة كلمة المرور:** يُطلب البريد، يُرسل كود إعادة تعيين، ثم تُحدَّث كلمة المرور.
- **الاشتراك:** صفحة لعرض خطط الاشتراك وتقديم طلب اشتراك مع رفع إيصال الدفع، مع تطبيق خصم كود الدعوة (25%).
- **الصفحة الرئيسية (لوحة تحكم الطالب):** تعرض الكورسات المرشَّحة حسب مرحلة الطالب وصفه وفصله الدراسي، مع الإعلانات وتلخيص لتقدمه (مدة المشاهدة، نسبة الإكمال، الشريط اليومي/التتابع).
- **الملف الشخصي:** يعدّل الطالب (الاسم، الهاتف، هاتف ولي الأمر، اسم ولي الأمر، بريد ولي الأمر، الصورة الرمزية، المحافظة). المرحلة والصف لا يُعدَّلان أثناء الاشتراك النشط.
- **الإعدادات:** تبديل الوضع الليلي (داكن/فاتح) وحفظه في الجلسة.
- **الإنجازات:** شاشة تعرض قائمة إنجازات يحققها الطالب مثل (أول درس، أول اختبار، إكمال 5/10/25/50/100 درس، مشاهدة 5/20 ساعة، مواظبة 7/30 يوماً، امتياز 100%، إكمال كورس كامل، 50 اختباراً).
- **الإشعارات:** مركز إشعارات يعرض الرسائل الموجَّهة للجميع أو للطالب أو لصفه أو لمرحلته، مع إمكانية تجاهل إشعار.
- **سجل النشاط:** يعرض آخر الأنشطة (إكمال درس، حل اختبار، فتح ملف PDF، تحقيق إنجاز).
- **تقدّم الطالب:** صفحة مفصّلة لتقدّمه عبر الكورسات والدروس والاختبارات والتتابع.
- **آخر درس / الدرس الحالي:** تُستنتجان من حالة تقدم الدروس (الدرس غير المكتمل التالي، وآخر درس مكتمل).
- **نسبة الإنجاز:** نسبة إكمال الدروس داخل كل كورس.
- **مدة المشاهدة:** إجمالي ثواني المشاهدة المتراكمة.
- **متوسط المشاهدة:** متوسط وقت المشاهدة لكل طالب (في لوحة المدرس).
- **الشريط اليومي (التتابع):** عدد أيام المذاكرة المتتالية (حالي وأطول).
- **ميزات أخرى:** وضع الزائر التجريبي، تطبيق كود دعوة، محادثة المعلم (اسأل عفيفي)، ربط ولي الأمر بدعوة، والوضع الليلي.

## القسم الثالث: الكورسات

- **عرض الكورسات:** تُعرض قائمة الكورسات مع تصفيتها تلقائياً حسب مرحلة الطالب وصفه وفصله الدراسي المحدد من إعدادات المدرس.
- **تفاصيل الكورس:** صفحة تعرض الأقسام والدروس وحالة تقدم الطالب في كل درس.
- **ترتيب الدروس:** الدروس مرتَّبة حسب حقل ترتيب داخل كل قسم.
- **قفل الدروس:** الدروس المقفلة تتطلب إكمال الدرس السابق (فتح متسلسل)، ما لم يكن الدرس مجانياً.
- **فتح الدروس:** يُفتح الدرس التالي تلقائياً عند إكمال سابقه؛ والدروس المجانية متاحة للجميع.
- **استكمال الدراسة:** يُحسب إكمال الكورس من نسبة الدروس المكتملة.
- **البحث والفلترة:** آلية العرض تعتمد التصفية حسب (المرحلة، الصف، الفصل الدراسي). وفي المراجعات توجد تصفية حسب الكورس.
- **نظام التقدم:** لكل كورس تُحفظ (نسبة الإكمال، عدد الدروس المكتملة، متوسط نسبة المشاهدة).
- **المراجعات:** نوع محتوى مستقل يحتوي فيديوهات وملفات PDF، يُعرض ضمن قسم المراجعات ويُصفّى حسب الكورس والمرحلة والصف.
- **الملاحظات:** نوع محتوى مستقل عبارة عن ملفات PDF للمشتركين فقط، يُصفّى حسب المرحلة والصف.

## القسم الرابع: الدروس

- **الفيديو:** يُشغَّل الفيديو عبر تضمين يوتيوب (يدعم روابط watch و youtu.be و embed و shorts) داخل مشغل بالصفحة.
- **استكمال المشاهدة:** يُرسل العميل نبضات دورية أثناء المشاهدة لتتبع الموضع والزمن.
- **حفظ آخر ثانية:** يُحفظ موضع الاستئناف (resumePosition) لكل درس ويعود إليه الطالب.
- **نسبة الإكمال:** تُحسب نسبة اكتمال الدرس من موضع التقدّم، ويُعتبر مكتملاً عند تجاوز 95%.
- **تشغيل الفيديو:** عبر مشغل يوتيوب مدمج في صفحة الدرس.
- **منع التحميل:** الفيديو مضمَّن من يوتيوب ولا يوجد رابط ملف مباشر متاح للطالب، مع سياسات حماية المحتوى.
- **ملف PDF:** يُفتح داخل عارض PDF خاص بالمنصة (انظر القسم الخامس).
- **الاختبار:** لكل درس اختبار اختياري يُفتح في صفحة مستقلة عند تفعيله.
- **الانتقال للدرس التالي:** التنقل بين الدروس عبر صفحة الدرس وحالة الفتح المتسلسل.
- **الدروس المقفولة:** تُعرض صفحة "الدرس مقفول" عند محاولة فتح درس غير مُتاح.
- **القيود الموجودة:** الدروس غير المجانية تتطلب اشتراكاً نشطاً؛ والدروس غير المجانية غير المكتملة تتطلب إكمال سابقها؛ والزائر التجريبي يرى فقط الدروس المسموح بعرضها للزوار.

## القسم الخامس: ملفات PDF

- **طريقة العرض:** تُعرض الملفات داخل عارض PDF بالمنصة بشكل تمرير عمودي مستمر (شبيه بأسلوب Google Drive)، مع تكبير/تصغير وتنقّل بين الصفحات.
- **طريقة الحماية:** الملفات مخزَّنة في مستودع خاص، ويُنشأ لها رابط موقَّع قصير الصلاحية على الخادم فقط ولا يصل للمتصفح، ويُعاد فحص الصلاحية (تسجيل الدخول/الاشتراك/مجانية الدرس) مع كل طلب.
- **التكبير / التصغير:** يدعم العارض التكبير والتصغير والانتقال لنسبة معيّنة.
- **الصفحات:** تُحمَّل الصفحات عند الحاجة أثناء التمرير، مع تخطيط يحافظ على نسبة الأبعاد ويدعم التنقّل.
- **الحفظ:** لا يوجد زر تنزيل مكشوف للطالب؛ يتم البث عبر نفس أصل المنصة فقط.
- **منع التحميل:** لا يوجد رابط مباشر للملف؛ الرابط الموقَّع يبقى داخل الخادم، والعارض لا يعرض خيار تنزيل.
- **منع الطباعة:** لا يوجد زر طباعة مكشوف للطالب داخل العارض.
- **طريقة إنشاء الرابط:** يُنشئ الخادم رابط بث من نفس الأصل عند طلب العارض، ثم يَستمد رابطاً موقَّعاً قصيراً من المستودع الخاص.
- **صلاحية الرابط:** الرابط الموقَّع صالح لمدة قصيرة (حوالي 60 ثانية) ويُعاد إنشاؤه لكل طلب.

## القسم السادس: الاختبارات

- **إنشاء الاختبار:** ينشئ المدرس اختبار الدرس (أسئلة متعددة الخيارات) واختبار الكورس (امتحان شامل).
- **رفع ملف Word:** يرفع المدرس ملفاً بصيغة Word فيستخرج النظام الأسئلة والخيارات والإجابة الصحيحة من عدة صيغ (جدول بفاصل جدولة، جدول Word، أو صيغة مرقّمة تقليدية) مع دعم أسئلة (صح/خطأ).
- **بنك الأسئلة:** ينشئ المدرس بنوك أسئلة لكل كورس، ويتصفحها الطالب.
- **استيراد الأسئلة:** عبر استخراجها من ملف Word المرفوع.
- **تصحيح الاختبار:** تُحسب النتيجة في جهة العميل وتُرسل (النتيجة، الإجمالي، الصحيح، الخاطئ، الزمن) فيُحفظ كل محاولة.
- **الدرجات:** تُحفظ نسبة كل محاولة.
- **إعادة المحاولة:** تُسجَّل محاولات متعددة لكل اختبار.
- **عرض النتائج:** تظهر نتائج الاختبارات في لوحة تقدّم الطالب.
- **تحليل النتائج:** في لوحة المدرس توجد تحليلات الاختبارات (عدد الطلاب، عدد المحاولات، متوسط الدرجات، نسبة النجاح، متوسط المحاولات، أعلى وأدنى درجة).

## القسم السابع: التحليلات

### الطالب
- **مدة المشاهدة:** إجمالي ثواني المشاهدة.
- **عدد الدروس:** عدد الدروس المكتملة.
- **الإنجازات:** قائمة الإنجازات المحققة.
- **متوسط الدرجات:** متوسط نسب اختبارات الطالب.
- **النشاط:** سجل الأنشطة الأخيرة.
- **آخر درس / الدرس الحالي:** كما في قسم الطالب.
- **سجل النشاط:** كما في قسم الطالب.

### المدرس / المسؤول
- **أكثر الطلاب نشاطاً / أقلهم:** ترتيب حسب درجة النشاط (يومياً/أسبوعياً/شهرياً).
- **أكثر الدروس نشاطاً / أقلها:** تحليل لكل درس (عدد الفتحات، نسبة الإكمال، متوسط وقت المشاهدة، درجة النشاط).
- **تحليل الاختبارات:** كما في قسم الاختبارات.
- **نسب الإكمال:** نسبة إكمال الدروس لكل كورس.
- **متوسط المشاهدة:** متوسط وقت المشاهدة لكل طالب.
- **عدد مرات الفتح:** عدد مرات فتح كل درس/ملف.
- **كل الإحصائيات:** إجمالي الطلاب، النشطون اليوم/هذا الأسبوع/هذا الشهر، غير النشطين، إجمالي وقت المشاهدة، متوسط وقت المشاهدة، الطلاب المكملون، متوسط درجة الاختبار، الأكثر نشاطاً، الأقل نشاطاً، الأكثر إكمالاً للدروس، تحليل الدروس، تحليل الاختبارات، ملخص كل الطلاب.

## القسم الثامن: لوحة المدرس (المسؤول)

- **لوحة رئيسية (Dashboard):** لمحة إحصائية سريعة (الطلاب، الاشتراكات النشطة، متوسط الإكمال، متوسط درجات الاختبارات، عدد الكورسات).
- **إدارة الطلاب:** عرض الطلاب، تعديل بياناتهم، حذفهم، التحكم في اشتراكاتهم، وتفعيل رموز الشحن.
- **إدارة الكورسات:** إنشاء/تعديل/حذف الكورسات والأقسام والدروس واختباراتها.
- **إدارة الاشتراكات:** إنشاء/تعديل/حذف خطط الاشتراك (الاسم، السعر، المرحلة، المدة).
- **المدفوعات:** مراجعة طلبات الدفع وإيصالاتها وحالتها.
- **الإعدادات:** بيانات الموقع (أرقام التحصيل، الفصل الدراسي الحالي، رابط الاجتماعات).
- **رموز الشحن (Charge Codes):** إنشاء رموز وتعديلها وحذفها لشحن/تفعيل اشتراكات.
- **الإعلانات:** إنشاء وإدارة الإعلانات التي تظهر في الشريط الإخباري ومركز الإشعارات.
- **الاقتباسات/الحكم:** إدارة العبارات المعروضة في المنصة.
- **إرسال إشعار:** مركز لإرسال إشعارات فورية موجَّهة (للجميع/لصف/لمرحلة/لطالب).
- **الحصص المباشرة:** إدارة الحصص (إنشاء/تعديل/حذف/بدء/إنهاء/إلغاء) وربطها بحساب الاجتماعات.
- **المذكرات:** إدارة ملفات المذكرات PDF.
- **المراجعات:** إدارة محتوى المراجعات (فيديوهات وPDF).
- **المحادثة:** الدردشة مع الطلاب (قائمة المحادثات + محادثة لكل طالب).
- **طلبات الاشتراك:** عرض الطلبات وقبولها/رفضها/حذفها.
- **التحليلات:** لوحة تحليلات شاملة (طلاب، دروس، اختبارات، تفاصيل طالب).
- **تقدّم الطلاب:** عرض مفصّل لتقدّم طالب محدد.

## القسم التاسع: الحصص المباشرة

- **إنشاء الحصة:** ينشئ المدرس حصة (عنوان، المادة، الصف، المرحلة، الوقت، المدة، كلمة المرور، خيارات الانضمام والانتظار والتسجيل) مع إنشاء اجتماع في حساب الاجتماعات عند الربط.
- **تعديلها:** تحديث بياناتها وحقولها المسموحة.
- **حذفها:** حذف الحصة نهائياً.
- **بدايتها:** تتحول الحالة إلى "مباشرة" ويُرسل إشعار فوري للطلاب المطابقين (صف/مرحلة) ويُحفظ في مركز الإشعارات.
- **نهايتها:** تتحول إلى "منتهية" ويُنهى اجتماع الاجتماعات.
- **تسجيل الحضور:** يُسجَّل انضمام الطالب ومغادرته ومدة بقائه.
- **العد التنازلي:** يُرسل إشعار "على وشك البدء" في وقت محدد (notifyAt) عبر مهمة دورية.
- **دخول الطالب:** تُعرض صفحة الحصة مع مشغّل الاجتماعات وتوقيع الدخول، وتُصفّى الحصص المعروضة حسب صف/مرحلة الطالب.
- **صلاحيات الطالب:** الانضمام للحصص المطابقة لصفه/مرحلته فقط.
- **صلاحيات المدرس:** إنشاء/بدء/إنهاء/إلغاء الحصص والتحكم بخياراتها.

---

## القسم العاشر: الإشعارات

- **الإشعارات الفورية:** إرسال إشعار فوري عبر الرسائل السحابية عند حدث (تفعيل اشتراك، بدء حصة، إلخ).
- **المجدولة:** إشعارات لها موعد محدد (لا يمكن في الماضي)، قابلة للتعديل والإلغاء والإرسال الفوري.
- **Push Notifications:** تسجيل رمز الجهاز وتخزينه لإرسال الإشعارات السحابية.
- **FCM:** نظام الرسائل السحابية لإرسال الإشعارات للتطبيق.
- **الشريط الإخباري:** الإعلانات التي يضعها المدرس وتظهر في واجهة الطالب.
- **الإعلانات:** كما في قسم لوحة المدرس؛ تُعرض في الشريط الإخباري ومركز الإشعارات وتُستهدف حسب الجميع/الصف/المرحلة/الطالب.

---

## القسم الحادي عشر: نظام الاشتراكات

- **شراء الاشتراك:** يختار الطالب خطة ويرفع إيصال الدفع مع كود العملية.
- **رفع إيصال الدفع:** تُحفظ صورة الإيصال وحالتها "قيد المراجعة".
- **مراجعة الطلب:** يراها المدرس في "طلبات الاشتراك" و"المدفوعات".
- **قبول الطلب:** يتحول الطالب إلى "مشترك نشط"، ويُحدَّد تاريخ الانتهاء حسب مدة الخطة، وتُفعَّل مرحلة الاشتراك، ويُسجَّل الدفع، ويُرسل إشعار.
- **رفض الطلب:** يُرفض الطلب ويُرسل إشعار للطالب.
- **انتهاء الاشتراك:** عند تجاوز تاريخ الانتهاء تُصبح الحالة "منتهية" ويفقد الطالب صلاحية المحتوى المدفوع.
- **الصلاحيات:** المحتوى المدفوع (دروس غير مجانية، مذكرات، بعض PDF) متاح للمشتركين النشطين فقط؛ والدروس المجانية متاحة للجميع.

## القسم الثاني عشر: الأمان

- **الجلسات (Sessions):** جلسات موقَّعة في ملف تعريف ارتباط، آمنة في الإنتاج (httpOnly)، بصلاحية 30 يوماً.
- **حماية CSRF:** فحص نفس المصدر (host/origin/referer) لكل الطلبات المغيِّرة للحالة.
- **تشفير كلمة المرور:** تُشفَّر كلمة المرور بخوارزمية scrypt مع ملح لكل كلمة، ومقارنة آمنة.
- **الروابط الموقَّعة (Signed URLs):** روابط قصيرة الصلاحية تُنشأ داخل الخادم فقط ولا تصل للمتصفح.
- **تحديد المعدل (Rate Limiting):** حدود لكل عنوان IP على نقاط الدخول والاشتراك واستعادة كلمة المرور والتحليلات.
- **منع تحميل PDF:** مستودع خاص، لا رابط مباشر، بث عبر نفس أصل المنصة فقط، مع إعادة فحص الصلاحية.
- **حماية الفيديو:** تضمين يوتيوب مع سياسات حماية المحتوى.
- **منع الوصول للمحتوى:** بوّابة صلاحية تمنع غير المشتركين من المحتوى المدفوع (مع استثناء الدروس المجانية والزائر التجريبي المسموح).
- **صلاحيات المستخدمين:** تحكّم عبر أدوار (طالب/مدرس/ولي أمر/زائر) يمنع الوصول غير المصرَّح به لكل مسار.

## القسم الرابع عشر: قاعدة البيانات

### المجموعات (Collections / Nodes)

- **users:** بيانات جميع المستخدمين (طالب/مدرس/ولي أمر) بما فيها الصلاحيات والاشتراك والتقدم والإنجازات ورمز الدعوة.
- **courses:** الكورسات وأقسامها ودروسها (فيديوهات وPDF واختبار) وحقول التصفية.
- **subscriptions:** خطط الاشتراك المعروضة للشراء.
- **subRequests:** طلبات الاشتراك المقدَّمة من الطلاب بانتظار المراجعة.
- **payments:** سجل المدفوعات والإيصالات وحالتها.
- **reviews:** محتوى المراجعات (فيديوهات وPDF) مع ربطها بكورس.
- **notes:** المذكرات (ملفات PDF للمشتركين) مع حقول التصفية.
- **questionBanks:** بنوك الأسئلة لكل كورس.
- **announcements:** الإعلانات المعروضة في الشريط الإخباري ومركز الإشعارات.
- **quotes:** الاقتباسات/الحكم المعروضة في المنصة.
- **settings:** إعدادات الموقع (أرقام التحصيل، الفصل الدراسي، رابط الاجتماعات).
- **notifications:** مركز الإشعارات الموجَّهة للطلاب.
- **scheduledNotifications:** الإشعارات المجدولة بوقت إرسال وحالتها.
- **dismissed/{userId}:** الإشعارات التي تجاهلها كل طالب.
- **contacts:** رسائل نموذج التواصل.
- **chargeCodes:** رموز الشحن لتفعيل الاشتراكات.
- **parentInvites:** دعوات ربط أولياء الأمور بالطلاب.
- **chats/{chatId}/messages:** رسائل المحادثة بين الطالب والمعلم.
- **studentAnalytics/{uid}:** تحليلات كل طالب (مشاهدة، تقدم الدروس، الكورسات، الاختبارات، الإنجازات، النشاط، التتابع).
- **liveSessions:** الحصص المباشرة وحالتها وبيانات الاجتماع.
- **liveSessionAttendance/{sessionId}/{userId}:** سجل حضور كل طالب في كل حصة.

### العلاقات
- **user → subscription:** حالة اشتراك الطالب وتاريخ انتهائه مخزَّنة في سجله، وتُنشَّط عند قبول طلب اشتراك (`subRequests`) أو استبدال رمز شحن.
- **user → progress:** تقدّم الطالب في الكورسات والدروس محفوظ في سجله وعبر `studentAnalytics`.
- **course → lessons → videos/pdfs/quiz:** الكورس يحوي أقساماً ودروساً، وكل درس يحوي فيديوهات وملفات PDF واختباراً.
- **course → reviews/notes:** المراجعات والمذكرات تُربط بالكورس عبر حقل المعرّف.
- **subscription plan → subRequests:** خطة الاشتراك تُستخدم عند تقديم طلب اشتراك.
- **notification → user:** الإشعارات تُستهدف بالجميع/الصف/المرحلة/الطالب، ويُسجَّل تجاهلها لكل طالب.
- **liveSession → attendance:** الحضور مرتبط بالحصة والطالب.
- **chat → user:** المحادثة مرتبطة بحساب الطالب.
- **analytics → course/lesson:** تحليلات الطالب تشير إلى الكورسات والدروس عبر المعرّفات.
